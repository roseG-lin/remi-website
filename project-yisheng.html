爻胜 YiSheng — 易学 × 统计双引擎

Elo + Dixon-Coles 统计模型 与 六爻 / 梅花易数 / 大六壬 融合的竞彩预测系统

Rust Node.js 六爻 梅花易数 大六壬
项目概述

把欧洲统计模型与中国古典决策智慧融合

爻胜 YiSheng 是一个双引擎竞彩预测系统。统计层用 Elo 评分 + Dixon-Coles 双变量 Poisson 模型，给出 1X2 概率与期望进球； 易学层则是原创的六爻 / 梅花易数 / 大六壬实现，覆盖时间起卦、纳甲、八宫、用神旺衰、体用分析。 最终通过 统计 70% + 易学 30% 加权融合，反向冲突时切观望，可选 EV/Kelly 决策建议。

统计引擎 Elo + DC

913 场国际赛校准的 Elo 评分体系 + Dixon-Coles 双变量 Poisson 模型，给出 1X2 概率与期望进球

六爻时间起卦

支持时间起卦与赔率起卦，纳甲、八宫、世应、用神旺衰，遵循 liuyao-zengshanbuyi-v1 流派规则

梅花易数

meihua-tiyong-v1 流派，体用分析、时间起卦、动静判断，与统计层结果做交叉验证

大六壬

四课三传、十二天将、课体判断，独立模块实现，100% 测试覆盖

融合决策

统计 70% + 易学 30% 加权，反向冲突切观望；可选 EV / Kelly 凯利公式仓位建议

回测验证

walk-forward backtest 输出 RPS / Brier / ECE 三大校准指标，P4-P8 改造前后对比可量化

API & CLI

快速对接与本地试用

CLI 单场预测

jingcai wc predict spain germany
→ 51.4% / 27.2% / 21.4%

融合预测

jingcai wc predict spain germany --fusion \
--home-odds 2.5 --draw-odds 3.2 --away-odds 3.5

回测

jingcai wc backtest
→ RPS / Brier / ECE

REST API
方法 路径 说明
GET /api/wc/teams 48 强按 Elo 降序
POST /api/wc/predict 单场预测（含可选 fusion / odds）
GET /api/wc/health 引擎 + 数据新鲜度
POST /api/hexagram/cast 六爻起卦（沿用旧接口）
POST /api/analyze 综合融合分析（沿用旧接口）
启动方式 
# 1. 编译 Rust 引擎（生成 target/release/jingcai.exe）
cargo build --release

# 2. 校准 Elo 评分（首次运行，读 913 场国际赛 → data/worldcup/elo-calibrated.json）
target/release/jingcai.exe wc calibrate

# 3. 启动 API + 前端
cd server
npm install --include=dev
node server.js

# 4. 访问 http://localhost:3001 → 顶部导航选 "世界杯"
